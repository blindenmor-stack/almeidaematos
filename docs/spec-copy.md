### 2. O que fazemos <a id="o-que-fazemos"></a>

**Eyebrow:** Áreas de atuação
**H2:** O que fazemos pelo seu caso

**Intro (2 linhas):**
O escritório atua em sete áreas ligadas a acidentes, doenças e direitos previdenciários. Cada uma tem uma equipe própria e uma página com o que avaliamos no seu caso.

**7 cards (título + 1 linha + link):**

1. **Auxílio-acidente**: Para quem sofreu um acidente e ficou com sequela, mesmo trabalhando. → `/beneficios/auxilio-acidente/`
2. **Auxílio-doença**: Para quem está afastado do trabalho por doença ou lesão. → `/beneficios/auxilio-doenca/`
3. **BPC/LOAS**: Para quem tem deficiência ou é idoso e precisa do benefício assistencial. → `/beneficios/bpc-loas/`
4. **Aposentadoria por invalidez**: Para quem não pode mais trabalhar por incapacidade permanente. → `/beneficios/aposentadoria-por-invalidez/`
5. **Pensão por morte**: Para a família de quem morreu contribuindo com o INSS. → `/beneficios/pensao-por-morte/`
6. **Aposentadoria PCD**: Para pessoas com deficiência que já completaram o tempo de contribuição. → `/beneficios/aposentadoria-pcd/`
7. **Indenização cível e trabalhista**: Para quem sofreu prejuízo e precisa ser indenizado, dentro ou fora do trabalho. → `/beneficios/indenizacao-civel-trabalhista/`

### 4. Como trabalhamos

**Eyebrow:** Atendimento
**H2:** Como a equipe conduz o seu caso

1. **Mensagem no WhatsApp**
Você conta o que aconteceu, no seu tempo. A equipe já começa a entender o caso na primeira resposta.

2. **Análise do caso**
Verificamos se há direito a benefício, indenização ou seguro. A resposta é direta, com base no que você contou.

3. **Documentos**
Reunimos hospital, empresa e INSS com você. Uma equipe de conferência revisa tudo antes de enviar.

4. **Pedido e processo eletrônicos**
O pedido no INSS é eletrônico, assim como o processo na Justiça, se for preciso. Você acompanha pelo WhatsApp.

## Checklist

### Escrita sem cara de IA (`skills/copy/escrita-sem-cara-de-ia.md`, seção 4)

- [x] Zero "não é X, é Y". Zero "sem X, sem Y". Zero travessão em todo o texto.
- [x] Nenhum par de adjetivos empilhados. Nenhum clichê de mercado.
- [x] Cada fato aparece uma vez por página (2015, 70+, CNPJ, OABs, endereço).
- [x] Voz ativa; "você" no centro, "a equipe" em vez de "nós"; sempre "para", nunca "pra".
- [x] Títulos curtos e descritivos; H2 nomeiam o conteúdo real ("O que fazemos pelo seu caso", não "Serviços").
- [x] Primeira frase de cada bloco carrega o recado; parágrafos curtos.
- [x] 1 negrito por bloco no fato/benefício nas respostas de FAQ; CTAs em verbo + objeto.
- [x] Lido em voz alta; sem tom de locução de propaganda.

### Compliance OAB (Provimento 205/2021, via `tom-de-voz.md`)

- [x] Sem valores de indenização ou de honorários.
- [x] Sem "grátis": usado "sem custo inicial".
- [x] Sem promessa de resultado ("vamos ganhar seu caso").
- [x] Sem sensacionalismo.
- [x] Sem "melhor/maior/líder" e sem ranking.
- [x] Números usados só os permitidos no briefing (2015, 70+, OABs, CNPJ, endereço); nenhum inventado.
